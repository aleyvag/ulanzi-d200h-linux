# scripts/

Icon-processing scripts. The full documentation (dependencies, config
files, expected folder structure, and workflow) lives in the parent
folder's README: [../README.md](../README.md).

- `create_icon_with_frame.py` — autocrop + fit + recolor + frame.
- `create_frame.py` — generate a standalone frame PNG.
- `compose.py` — combine several icons into one.
- `utils.py` — shared helpers (not run directly).

You edit the YAML config files, not the code.
